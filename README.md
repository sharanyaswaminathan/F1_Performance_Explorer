# F1 Performance Explorer

An interactive dashboard for analyzing real Formula 1 session telemetry using Python and FastF1.

## What it analyzes

- Speed comparison between two drivers
- Delta time around a lap
- Braking points
- Approximate minimum cornering speeds

## Data

This project uses real telemetry from the 2024 Bahrain Grand Prix qualifying session.

The data includes speed, throttle, brake, distance, timing, and other telemetry channels provided by FastF1.
